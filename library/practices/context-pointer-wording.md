Word the pointer so the agent reaches the material at the right moment.

The pointer's wording decides when the agent follows it and how reliably. A pointer that names the
trigger — "when you add a gate, read …" — is reached at the moment it applies; one that names a
topic — "more detail" — is reached only if the agent already suspects the material exists. The
pointer is the whole mechanism: the material behind it costs nothing until it is followed, so a
pointer nobody follows is the same as no material at all.

The prose around a generated block is the same kind of surface. The block is rendered from the
selection, so a hand-edit is drift, and the sentence that says so is what keeps the next session
from editing it; the invariants in the detail doc are read by the agent that follows the pointer,
and they are the only place the rule is stated where that agent looks.

No gate reads the wording. It is judgement, and the test is behavioural: if the agent keeps missing
the material, the pointer is the defect, not the material.
