What does the skill remember about what it wrote?

The skill writes config files into your project and records what it wrote in a small file, .code-quality.json. Every later run compares that record against your actual files and says what it would do. The question this demo lets you explore: does this state model feel right? Press the buttons — nothing is saved, and no real file is touched.
